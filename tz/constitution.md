Бэкенд-сервис (Node.js):
	
описание 
	
	Принимает заказы из внешней системы через REST API.
	Управляет жизненным циклом заказа: создание, назначение курьера, отслеживание статуса, завершение.
	Обеспечивает аутентификацию и авторизацию курьеров и операторов.
	Отправляет push-уведомления курьерам о новых заказах и изменениях статуса.
	Предоставляет API для мобильных и десктопных приложений.
	Возможности: Заказы и статусы, Геопозиция курьеров, real-time отслеживание курьера, История маршрутов, Пользователи и роли, аналитика / отчёты, дашборды
	Аутентификация через смс, telegram, логин/пароль
	Роли пользователей: Администратор, владелец, менеджер, оператор заказов, курьер
	Система кошелька для курьера. Начисление за выполненный заказ. Вывод средств
	Смены курьера. Открытие смены для начала работы 
	

Технологический стек
Бэкенд:

	Node.js NestJS
	База данных: PostgreSQL, Redis ( для real-time слоя )
	Аутентификация: JWT
	Реалтайм: WebSocket (Socket.IO)
	Внешние интеграции: REST API для приема заказов
	Очереди: Redis + BullMQ (для фоновых задач)
	Push-уведомления: Firebase Cloud Messaging (FCM)
	Документация API: Swagger/OpenAPI
	Фронтенд (мобильные и десктоп приложения):

Инфраструктура:

	Docker (контейнеризация сервисов)
	CI/CD: GitHub Actions
